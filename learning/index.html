01 · Mental model

Quicksort’s focused cousin

A full sort organizes every value. Quickselect asks which side contains one target index and abandons the other side.

1

Choose a pivot

Any value can be the pivot. This lesson uses the last value.

2

Partition

Move smaller values left, then place the pivot between both sides.

3

Compare positions

Compare the pivot index with k - 1, the target index.

4

Discard one side

Continue only where the target index can still exist.

The partition contract

After partition returns p:

values < pivot pivot at p values ≥ pivot

The sides are not fully sorted. The pivot alone is guaranteed to be at its final sorted index.

03 · Encode the pattern

Two loops, two responsibilities

The inner loop partitions one range. The outer loop decides which range survives.

quickselect.py
◉ Recall mode

Say the partition contract out loud before revealing the code.

def quickselect(nums, k):
    nums = list(nums)
    def partition(lo, hi):
        pivot = nums[hi]
        i = lo
        for j in range(lo, hi):
            if nums[j] < pivot:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
        nums[i], nums[hi] = nums[hi], nums[i]
        return i

    target = k - 1
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        p = partition(lo, hi)
        if p == target:
            return nums[p]
        if p < target:
            lo = p + 1
        else:
            hi = p - 1
    return None

04 · Know the cost

Why the average is linear

Average time O(n)

Each partition scans its active range, but only one side survives. The work resembles n + n/2 + n/4 + …

Worst time O(n²)

Consistently choosing an extreme pivot can shrink the range by only one value per round.

Extra space O(1)

Partitioning can happen in place. Copying the input first changes this implementation to O(n) extra space.

Approach Typical time What it computes
Sort then index O(n log n) Every sorted position
Quickselect O(n) average One sorted position
Heap of size k O(n log k) Useful for streaming data
